# LeetCode Solutions

Este repositório contém minhas soluções para problemas do LeetCode.

O objetivo é praticar lógica de programação, estruturas de dados e melhorar a capacidade de resolver problemas.

As soluções estão organizadas por categorias e/ou dificuldades.

## Linguagens

* JavaScript
* C++

## Observação

Este repositório está em constante atualização conforme resolvo novos problemas.
